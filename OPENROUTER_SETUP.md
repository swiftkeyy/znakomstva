# OpenRouter Setup Guide

## Что такое OpenRouter?

OpenRouter — это единый API для доступа к различным AI моделям, включая бесплатные модели от Meta (Llama).

## Получение API ключа

1. Перейдите на https://openrouter.ai/
2. Зарегистрируйтесь или войдите
3. Перейдите в раздел "Keys": https://openrouter.ai/keys
4. Создайте новый API ключ
5. Скопируйте ключ (он показывается только один раз!)

## Настройка бота

1. Откройте файл `.env` в корне проекта
2. Добавьте ваш API ключ:

```env
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ-здесь
```

3. (Опционально) Настройте модели:

```env
# Модели по умолчанию (бесплатные)
OPENROUTER_TEXT_MODEL=meta-llama/llama-3.2-3b-instruct:free
OPENROUTER_VISION_MODEL=meta-llama/llama-3.2-11b-vision-instruct:free
OPENROUTER_REASONING_MODEL=meta-llama/llama-3.2-3b-instruct:free
```

## Доступные бесплатные модели

OpenRouter предоставляет несколько бесплатных моделей:

### Текстовые модели:
- `meta-llama/llama-3.2-3b-instruct:free` - быстрая модель для общих задач
- `meta-llama/llama-3.2-1b-instruct:free` - очень быстрая, но менее точная
- `google/gemma-2-9b-it:free` - альтернатива от Google

### Vision модели (с поддержкой изображений):
- `meta-llama/llama-3.2-11b-vision-instruct:free` - анализ изображений
- `meta-llama/llama-3.2-90b-vision-instruct:free` - более мощная версия

## Лимиты бесплатного тарифа

- **Запросы**: Без жестких лимитов, но есть rate limiting
- **Токены**: Ограничение на количество токенов в минуту
- **Модели**: Доступны только модели с пометкой `:free`

## Переход на платный тариф

Если бесплатных лимитов недостаточно:

1. Пополните баланс на https://openrouter.ai/credits
2. Получите доступ к более мощным моделям:
   - `anthropic/claude-3.5-sonnet`
   - `openai/gpt-4-turbo`
   - `google/gemini-pro-1.5`

## Мониторинг использования

Отслеживайте использование API на https://openrouter.ai/activity

## Troubleshooting

### Ошибка "Invalid API key"
- Проверьте, что ключ скопирован полностью
- Убедитесь, что в `.env` нет лишних пробелов
- Ключ должен начинаться с `sk-or-v1-`

### Ошибка "Rate limit exceeded"
- Подождите несколько минут
- Рассмотрите возможность пополнения баланса
- Используйте кэширование для уменьшения количества запросов

### Медленные ответы
- Попробуйте более легкую модель (1b вместо 3b)
- Уменьшите `max_tokens` в запросах
- Проверьте интернет-соединение

## Сравнение с Ollama

| Параметр | OpenRouter | Ollama |
|----------|-----------|--------|
| Установка | Не требуется | Требуется локальная установка |
| Стоимость | Бесплатный tier + платные модели | Полностью бесплатно |
| Скорость | Зависит от сети | Зависит от железа |
| Модели | Доступ к множеству моделей | Нужно скачивать каждую модель |
| Приватность | Данные отправляются на сервер | Все локально |

## Рекомендации

Для production использования рекомендуется:
1. Настроить мониторинг использования API
2. Реализовать fallback на другие модели при ошибках
3. Использовать кэширование для частых запросов
4. Установить лимиты на количество запросов от одного пользователя
